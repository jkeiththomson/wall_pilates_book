------------------------------
Exercise infographic structure
------------------------------

Canvas: 8.5x11 portrait, 0.75" margins

Structure:

└── Header (vert container)              # main data file
	└── Title (text, one line)

└── Info (horz container)              # main data file
	└── Domino (vert container)
      	└── Top (vertical container)
  	      	├── LEVEL label
 	      	└── Level (1, 2 or 3 dots)
      	└── Bottom (vert container)
  	      	├── REPS label
  	      	└── Reps (number)
    └── Feature (vert container)
  	    └── Works (text block, variable length)
		└── Benefits (text block, variable length)
	└── Imagery Icon (image - sun) 
    	└── Imagery Text (text block, variable length)

└── Body (horz container)              # main data file
	└── Thumbnails (vert container)
      	├── Thumb1 (image, fixed size)
      	├── Thumb2 (image, fixed size)
      	├── Thumb3 (image, fixed size)
	└── Instructions (vert container)
      	├── Placement (text, variable size) 
      	├── Movement (text, variable size) 
      	└── Breath (text, variable size) 

└── Footer (horz container)
	└── Tips Icon (image)
		└── Tips (text, variable length)
	└── Caution Icon (image)
		└── Caution (text, variable length)
	└── QR Code (image)
